# REPO CONTEXT
This file contains important context about this repo for [Tonkotsu](https://www.tonkotsu.ai) and helps it work faster and generate better code.

## Setup Commands
- Initial setup: `npm install`

## Development Commands
- Run dev server: `npm run dev`
- Build the project: `npm run build`
- Preview the build: `npm run preview`

## Deployment Commands
- Deploy to GitHub Pages: `npm run deploy`
- Open deployed site: `npm run open`

## Repository Structure
This is a P5.js project using Vite as the build tool. The main sketch is in `src/sketch.js` and the HTML entry point is `index.html`.

## Notes
- No specific lint or test commands are defined in the project
- The project uses p5.js for creative coding
- Dependencies include file-saver, p5, p5js-wrapper, and tweakpane
